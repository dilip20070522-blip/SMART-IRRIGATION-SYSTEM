# Smart Irrigation System

 ## Overview
The Smart Irrigation System is an Arduino-based irrigation solution that helps farmers manage water efficiently. The system monitors soil moisture and temperature, estimates irrigation time, and controls water distribution through a mobile application using Bluetooth communication.

## Features
- Real-time soil moisture monitoring
- Temperature monitoring
- Irrigation time estimation
- Bluetooth-based mobile control
- Multi-section irrigation management
- Automatic pump and valve control

## Components Used
- Arduino Uno
- HC-05 Bluetooth Module
- Soil Moisture Sensors
- Temperature Sensor
- Relay Module
- Solenoid Valves
- Water Pump
- OLED Display
